## 记录
### 第一类 世界贸易组织《渔业补贴协定》谈判

点击顺序：

1. 点击“世界贸易组织《渔业补贴协定》谈判”。
2. 选择以下四类会议入口之一：
    - 规则谈判组正式会议
    - 主席主持的开放式非正式磋商
    - 小范围成员磋商
    - 双边或多边非正式磋商
3. 如果选择“主席主持的开放式非正式磋商”，继续显示六个核心议题，用户选择一个。
4. 点击“下一步”，设置参与方。
5. 点击“下一步”，生成谈判基础信息。

即：

`议题场景 → 会议入口 → 核心议题（仅第二类会议需要）→ 参与方 → 生成内容`

其他三类会议入口不显示这六个固定核心议题：

- 规则谈判组正式会议：选择后直接进入相应正式会议。
- 小范围成员磋商：选择后填写磋商议题，并在参与方步骤指定成员。
- 双边或多边非正式磋商：选择后填写磋商议题，并在参与方步骤指定两个或多个成员。

### 第二类 印度洋金枪鱼委员会区域渔业治理

点击顺序：

1. 点击“印度洋金枪鱼委员会区域渔业治理”。
2. 显示五个核心议题，用户选择一个：
    - 捕捞配额与资源总量管控
    - 生态保护与兼捕管控
    - 渔船产能与作业管控
    - 履约监管与措施实施
    - 沿海国权益与渔业经济
3. 系统显示该核心议题下的具体机构会议。
4. 用户选择一场具体机构会议。
5. 点击“下一步”，设置参与方。
6. 点击“下一步”，生成谈判基础信息。

即：

`议题场景 → 核心议题 → 具体机构会议 → 参与方 → 生成内容`
