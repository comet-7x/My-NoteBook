
在产生任何动作之前，都需要知道自己为什么做。
1. 想清楚自己要解决什么问题
2. 我准备用什么方法，为什么使用这个方法？
3. 什么结果才算做完？
4. 我现在最可能错在哪里？
形成：
> **想 → 做 → 检查 → 调整 → 做 → 总结**

而不是以前：
> **做 → 做 → 做 → 做 → 很累 → 下班。**

**行动前 3 分钟：**
> 我要解决什么？  
> 为什么这样做？  
> 什么叫完成？  
> 哪里可能错？


任务的完成应该是：完成 = 做出来 + 想明白 + 讲得出来。

每天晚上只写这五句话：

> **今天我做了什么？**
> 
> **哪件事情我是没想清楚就开始做的？**
> 
> **我当时为什么会直接行动？**
> 
> **如果重来，我应该在哪一个时间点停下来？**
> 
> **明天遇到类似情况，我准备怎么做？**
