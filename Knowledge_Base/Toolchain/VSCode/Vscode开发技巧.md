# VSCode 开发常用快捷键速查表（Windows / Mac 通用）

本笔记整理日常开发高频 VSCode 快捷键，适配 **Windows、Mac 双系统**，统一归类常用面板操作、代码格式化、代码折叠展开功能，适合日常快速查阅、提升编码效率。

## 一、JSON 快速格式化

一键格式化混乱的 JSON 代码，自动缩进、对齐排版，无需手动调整格式。

- **Windows**：`Ctrl + Shift + F`
    
- **Mac**：`Cmd + Shift + F`
    

## 二、底部终端/面板操作

### 2.1 打开 / 关闭底部面板（终端、输出、问题栏）

快速隐藏或唤起底部所有功能面板，最大化代码编辑区域。

- **Windows**：`Ctrl + J`
    
- **Mac**：`Cmd + J`
    

### 2.2 新建底部终端面板

在底部快速新建一个独立终端窗口，支持多终端并行操作。

- **Windows**：`` Ctrl + Shift + ` ``
    
- **Mac**：`` Cmd + Shift + ` ``
    

## 三、代码展开与折叠（高频编码操作）

快速折叠/展开代码块、函数、类、全部代码，精简视图，方便阅读长文件代码。

### 3.1 折叠当前代码块

- **Windows**：`Ctrl + Shift + [`
    
- **Mac**：`Cmd + Shift + [`
    

### 3.2 展开当前代码块

- **Windows**：`Ctrl + Shift + ]`
    
- **Mac**：`Cmd + Shift + ]`
    

### 3.3 折叠文件所有代码

- **Windows**：`Ctrl + K + 0`
    
- **Mac**：`Cmd + K + 0`
    

### 3.4 展开文件所有代码

- **Windows**：`Ctrl + K + J`
    
- **Mac**：`Cmd + K + J`
    

## 四、高频代码编辑快捷键（核心常用）

日常编码核心操作，快速增删、移动、注释代码，大幅提升编写效率，双系统适配。

### 4.1 快速注释代码

一键单行注释/取消注释，适配所有编程语言。

- **Windows**：`Ctrl + /`
    
- **Mac**：`Cmd + /`
    

### 4.2 快速删除当前行

无需选中整行，一键删除光标所在代码行。

- **Windows**：`Ctrl + Shift + K`
    
- **Mac**：`Cmd + Shift + K`
    

### 4.3 上下移动当前行

无需剪切粘贴，快速调整代码行顺序。

- **Windows**：`Alt + ↑ / ↓`
    
- **Mac**：`Option + ↑ / ↓`
    

### 4.4 复制当前行到上下行

快速复用代码，无需手动复制粘贴。

- **Windows**：`Shift + Alt + ↑ / ↓`
    
- **Mac**：`Shift + Option + ↑ / ↓`
    

### 4.5 选中相同单词（批量修改）

依次选中多个相同变量/字段，实现批量同步修改。

- **Windows**：`Ctrl + D`
    
- **Mac**：`Cmd + D`
    

### 4.6 选中整行代码

快速选中光标所在完整代码行。

- **Windows**：`Ctrl + L`
    
- **Mac**：`Cmd + L`
    

## 五、文件与窗口操作快捷键

快速管理编辑标签页、文件窗口，简化窗口切换与关闭操作。

### 5.1 关闭当前文件标签页

- **Windows**：`Ctrl + W`
    
- **Mac**：`Cmd + W`
    

### 5.2 新建空白文件

- **Windows**：`Ctrl + N`
    
- **Mac**：`Cmd + N`
    

### 5.3 保存当前文件

- **Windows**：`Ctrl + S`
    
- **Mac**：`Cmd + S`
    

### 5.4 全局保存所有文件

- **Windows**：`Ctrl + Shift + S`
    
- **Mac**：`Cmd + Shift + S`
    

### 5.5命令行窗口分栏
- **Windows**：
    
- **Mac**：`Cmd + \`


## 六、查找与代码跳转快捷键

快速检索代码、跳转行号、查看代码定义，适配大型项目开发。

### 6.1 全局搜索内容

在整个项目中搜索关键字、代码片段。

- **Windows**：`Ctrl + Shift + F`
    
- **Mac**：`Cmd + Shift + F`
    

### 6.2 页内查找匹配内容

在当前打开文件中检索内容。

- **Windows**：`Ctrl + F`
    
- **Mac**：`Cmd + F`
    

### 6.3 跳转到指定行号

输入行号快速精准跳转代码位置，适配报错定位场景。

- **Windows**：`Ctrl + G`
    
- **Mac**：`Cmd + G`
    

### 6.4 预览代码定义（不跳转）

悬浮预览函数、变量源码定义，不切换当前编辑页面。

- **Windows**：`Alt + F12`
    
- **Mac**：`Option + F12`
    

### 6.5 批量重命名变量/函数

全局统一修改标识符名称，避免手动修改遗漏。

- **Windows**：`F2`
    
- **Mac**：`F2`
    

## 七、使用说明

- 所有快捷键为 VSCode 默认原生快捷键，无需额外安装插件、无需自定义配置；
    
- Windows 统一使用 `Ctrl / Alt` 组合键，Mac 统一替换为 `Cmd / Option` 组合键，记忆成本低；
    
- 适用于 Python、JSON、前端等全品类文件开发，通用无限制。
